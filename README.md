# DuskBridge

DuskBridge is a real-time event-driven microservices architecture that enables and establishing a highly available hub for data exchange.

With DuskBridge, you get a lightweight tool that stays out of your way.

**What you get**

- DuskBridge is a real-time event-driven
- microservices architecture that enables and
- establishing a highly available hub

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/DuskBridge.git`
2. `cd DuskBridge`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
